## What Was Added to the 9.4 Version

1. Tablet breakpoint (900px and below): the hero becomes one column with centered text, and the feature cards change to 2 columns.
2. Mobile breakpoint (600px and below): the navbar stacks vertically with wrapping links and a full-width button, the hero buttons stack, the feature cards change to 1 column, and the footer text is centered.
3. Typography: the heading and paragraph font sizes become smaller on tablet and mobile.
4. Images: all images use max-width: 100% and height: auto, and the hero image uses object-fit: cover so it never stretches.
5. Smooth scrolling and scroll-padding-top, so the sticky navbar does not cover the section headings when a link is clicked.

## Testing
